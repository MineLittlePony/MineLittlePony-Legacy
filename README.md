# MineLittlePony

This is an **unofficial** fork of a decompiled version of the original ModLoader version of [Mine Little Pony](https://github.com/MineLittlePony/MineLittlePony/),
rewritten to be compatible with Ornithe on Minecraft 1.2.5.

All code belongs to the original Mine Little Pony developers and contributors - I have simply "updated" it a bit, with permission from the MineLittlePony team.
