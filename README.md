# MineLittlePony

Turns players into ponies.

**If you are using a version of Minecraft other than 1.2.5 (released in April of 2012), this isn't the right page for you!
You probably want [the current version of the mod](https://github.com/MineLittlePony/MineLittlePony).**

[https://minelittlepony-mod.com/](https://minelittlepony-mod.com/)

This is a semi-unofficial fork/update of Mine Little Pony for Minecraft 1.2.5, for those of us who loved being a pony back then,
but want to use more modern Ornithe mods in your game as well!

As a bonus, you get working skins, both from the official Mojang server, and Mine Little Pony's custom HD skin server.

This fork is currently maintained by [AppleDash](https://github.com/AppleDash). You can find him on the Mine Little Pony Discord server,
and any questions about this mod should be directed to him - not the rest of the team!

## Building

1) JDK 8 or higher is required.
2) Open a terminal window in the same directory as the sources (git clone or extracted from zip). Run the following command (Windows):

```
gradlew build
```

or Linux:

```
./gradlew build
```

3) After some time, the built mod will be in `build/libs`.

## Installation

[Ornithe](https://ornithemc.net/) is required. Please follow [their instructions](https://ornithemc.net/download/) for installation, and come back once you have Ornithe functioning.

**Remember to use the Ornithe launcher profile when starting the game!**
